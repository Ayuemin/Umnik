# История изменений

Все заметные пользовательские изменения Umnik фиксируются здесь. Формат ориентирован на Keep a Changelog, версии следуют Semantic Versioning.

## Unreleased

## v1.3.6 - 2026-09-12

- Повторное нажатие «Новый чат» больше не создаёт цепочку пустых диалогов: чистый пустой чат переиспользуется, а старые глобальные пустышки из предыдущих версий постепенно убираются при создании нового чата.
- В «Истории чатов» добавлена кнопка «Очистить все чаты» с обязательным подтверждением. Сгенерированные файлы и экспорт в хранилище Umnik при этом не удаляются.
- Свайп слева направо для открытия меню теперь работает по всей области чата, а не только от края экрана. Горизонтально прокручиваемые вложения, включая Markdown-таблицы, получают приоритет и не должны открывать меню вместо прокрутки.
- NVIDIA FLUX.1-schnell временно убран из проверенного каталога Umnik: hosted endpoint NVIDIA сейчас нестабилен и может зависать без ответа. Уже сохранённый выбор автоматически переводится на первый доступный проверенный NVIDIA image-модель.
- Реестр провайдеров поднят до версии 3, чтобы старый кэш с FLUX.1-schnell сбросился сразу после обновления приложения.

## v1.3.5 - 2026-09-12

- Возвращён компактный пульсирующий Stop: нажатием на него запрос по-прежнему можно остановить, а время работы модели теперь ненавязчиво показывается по центру пустого поля ввода.
- Верхняя панель стала компактнее: слева направо расположены меню, новый чат, баланс OpenRouter и быстрая модель; текст «Меню» заменён на значок из трёх полос.
- Меню можно открыть жестом слева направо от левого края экрана.
- Перед очисткой текущего чата теперь обязательно показывается подтверждение, защищающее от случайного удаления переписки.
- Исправлена интеграция NVIDIA FLUX.1-schnell: облачный запрос приведён к минимальному официальному формату NVIDIA без нестабильных width/height; ожидание NVIDIA Image API увеличено до 10 минут, при этом запрос всегда можно остановить вручную.
- Для FLUX.1-schnell временно оставлен безопасный формат 1:1 в обновляемом реестре, пока облачный endpoint NVIDIA нестабилен с произвольными размерами.
- OpenRouter SVG теперь сохраняется с расширением `.svg`. Непросматриваемые и неизвестные файлы больше не пропадают: Umnik показывает карточку-заглушку с кнопками «Скачать» и «Поделиться».
- FileProvider расширен на сгенерированные файлы, поэтому ими можно безопасно делиться прямо из чата.
- Кнопка «Поделиться» под текстовым ответом теперь отправляет читаемый текст без служебных Markdown-символов `#`, `*`, обратных кавычек и других маркеров; копирование и скачивание ответа остались без изменений.

## v1.3.4 - 2026-09-12

- Исправлен выбор текстовой модели: выбранные поставщик и модель теперь действительно переключают текущий чат и становятся значениями по умолчанию для новых чатов.
- После смены поставщика выбранная модель сразу становится текущей и видна в быстром списке моделей в шапке чата.
- Исправлено переключение в обе стороны между NVIDIA и OpenRouter.
- Из каталога NVIDIA удалены Stable Diffusion 3 Medium и Stable Diffusion XL: NVIDIA пометила их бесплатные endpoint-ы как deprecated.
- FLUX.1-schnell теперь отправляется по официальному примеру NVIDIA с `seed=0` и `steps=4`; при 400/422 выполняется один повтор без необязательных размеров.
- Реестр провайдеров поднят до версии 2, поэтому старый кэш с недоступными image-моделями сбрасывается после обновления приложения.

## v1.3.3 - 2026-09-12

- Квадратный секундомер запроса уменьшен с сохранением удобной области нажатия; цифры уменьшены пропорционально.
- Выбор текстовой и image-модели в настройках теперь двухэтапный: сначала модель отмечается галочкой, затем пользователь явно нажимает «Сохранить выбор».
- Исправлена ситуация, когда новая текстовая модель по умолчанию сохранялась, но текущий чат продолжал использовать старую модель из-за сохранённого override: для текущего подключения старый override теперь снимается.
- При сохранении текстовой модели текущего подключения она сразу применяется к текущему чату и становится моделью по умолчанию для новых чатов.
- При выборе модели другого подключения Umnik сохраняет её только для этого подключения и явно сообщает, что текущий чат не переключался на другой сервис.
- Сохранение выбранной текстовой и image-модели переведено на синхронную запись настроек, чтобы исключить визуальное подтверждение до фактической фиксации выбора.

## v1.3.2 - 2026-09-12

- Пульсирующий значок остановки во время запроса заменён на крупный квадратный секундомер в поле ввода.
- Секундомер показывает полное время текущего запроса в формате `м:с`, включая ожидание очереди у провайдера и сетевую задержку.
- Нажатие прямо на секундомер по-прежнему немедленно останавливает активный запрос; отдельный стоп-значок больше не нужен.
- После ответа, ошибки или остановки таймер сбрасывается и снова появляется обычная кнопка отправки.

## v1.3.1 - 2026-09-12

- Исправлен HTTP 422 у NVIDIA NIM: Umnik больше не отправляет необязательный `mode` и другие лишние поля там, где для text-to-image достаточно минимального запроса.
- Для NVIDIA добавлен защитный повтор: если провайдер отклоняет необязательное поле как `extra_forbidden`, запрос один раз повторяется только с обязательными полями модели.
- Проверены схемы всех встроенных Image API: OpenRouter получает только заявленные моделью параметры, NVIDIA использует отдельные payload для FLUX/SD3/SDXL, а OpenAI-compatible остаётся на минимальном `model + prompt`.
- Пользовательский OpenAI-compatible Image API теперь принимает как базовый URL, так и полный endpoint, заканчивающийся на `/images` или `/images/generations`.
- У текстового запроса на генерацию изображения появилась кнопка повтора; для неё используется подпись «Сгенерировать снова».
- Параметры `aspect_ratio` и `resolution` больше не отправляются в OpenRouter, если выбранная image-модель не объявляет их в `/images/models`.

## v1.3.0 - 2026-09-12

- Генерация изображений разделена на адаптеры провайдеров: OpenRouter использует свой Image API, а NVIDIA NIM — отдельный `ai.api.nvidia.com/v1/genai/<model>` вместо общего `/models` и `/images/generations`.
- Встроено подключение NVIDIA с отдельным списком настоящих генераторов изображений: FLUX.2 Klein 4B, FLUX.1 Schnell, FLUX.1 Dev, Stable Diffusion 3 Medium и Stable Diffusion XL.
- Исправлена смена провайдера изображений: модель от предыдущего сервиса больше не остаётся выбранной под другим подключением.
- В «Подключениях» появились дополнительные настройки Image API: включение генерации, отдельный адрес, протокол `Авто / OpenAI-compatible / NVIDIA NIM`, общий или отдельный API-ключ.
- Для OpenRouter и NVIDIA стандартные адреса подставляются автоматически; при необходимости пользователь может отключить автоматические адреса и задать свои вручную.
- Добавлен обновляемый реестр провайдеров `docs/provider-registry.json`: Umnik раз в сутки проверяет актуальные адреса и список NVIDIA image-моделей, хранит последнюю рабочую копию и имеет встроенный офлайн-резерв.
- Старое пользовательское подключение Nvidia автоматически распознаётся и переводится на встроенный NVIDIA-адаптер без потери сохранённого ключа и настроек модели.
- Для произвольного OpenAI-совместимого сервиса Umnik больше не выдаёт общий `/models` за список генераторов: ID image-модели задаётся явно.
- Добавлена кнопка «Проверить подключение» с диагностикой текстового API и Image API без платной пробной генерации.

## v1.2.2 - 2026-09-12

- Экран «Текстовая модель» теперь показывает все включённые подключения, как «Быстрые модели» и выбор модели изображений.
- Для каждого подключения можно отдельно выбрать и сохранить собственную текстовую модель по умолчанию, например одну для OpenRouter и другую для Nvidia NIM.
- Выбор модели по умолчанию для другого подключения не переключает текущий чат на этот сервис.
- Каталог моделей выбранного подключения загружается через его собственный `/models`.

## v1.2.1 - 2026-09-12

- Стабильный релиз индикатора расходов OpenRouter после проверки beta-версий.
- Рядом с моделью показывается компактный расход за сегодня; по нажатию доступны день, неделя, месяц и всё время.
- После генерации изображения расход обновляется сразу и повторно через 2.5 секунды, чтобы учесть задержку обновления статистики OpenRouter.
- Название модели прижато к левому краю, а диагностика ошибок OpenRouter 403 стала понятнее.

## v1.2.1-beta.2 - 2026-09-12

- Название выбранной модели прижато к левому краю верхней панели и больше не центрируется в свободной области.
- Плашка расходов стала компактнее: рядом с моделью показывается только сумма, например `$0.37`, без слова «Сегодня».
- Для запросов чата OpenRouter включены router metadata, чтобы ошибки 403 по guardrails и политике безопасности давали более понятную причину.
- Общая ошибка `Access denied by security policy` теперь объясняется как ограничение OpenRouter/провайдера, а не как сбой счётчика расходов.

## v1.2.1-beta.1 - 2026-09-12

- Рядом с выбранной моделью OpenRouter добавлен компактный показатель расходов за сегодня.
- По нажатию показываются расходы текущего API-ключа за день, неделю, месяц и всё время.
- Статистика берётся напрямую из `GET /api/v1/key`, поэтому не обнуляется при закрытии или обновлении Umnik.
- Показатель обновляется при запуске приложения, после успешного запроса через OpenRouter и вручную из окна статистики.
- Название выбранной модели в верхней панели сделано компактнее, чтобы модель, статистика и кнопки не толкались на узком экране.

## v1.2.0 - 2026-09-11

- Стабильный релиз после серии beta 1.2.0.
- Добавлены несколько подключений: встроенный OpenRouter и произвольные OpenAI-совместимые API, с автоматическим выбором нужного подключения при переключении быстрой модели.
- Генерация изображений работает как изолированный запрос внутри обычного чата; модель изображений выбирается отдельно, а для OpenRouter доступны поддерживаемые моделью соотношение сторон и разрешение.
- Для несовместимых сочетаний размера и формата Umnik умеет безопасно повторить запрос с разрешением «Авто», сохраняя выбранное соотношение сторон.
- Добавлены голосовые сообщения: микрофон активен только у моделей OpenRouter с аудиовходом, запись отправляется как WAV без предварительного распознавания в текст.
- Исправлен звук готового ответа и упрощены уведомления интерфейса.
- Сохранены проекты, навыки, локальные файлы, ветвление чатов, Markdown, TTS, reasoning и web search.


## v1.2.0-beta.7 - 2026-09-11

- Исправлена генерация изображений для сочетаний параметров, которые модель заявляет как поддерживаемые по отдельности, но отклоняет вместе из-за минимального числа пикселей.
- Если OpenRouter возвращает такую ошибку для явно выбранного разрешения, Umnik один раз автоматически повторяет запрос с разрешением «Авто», сохраняя выбранное соотношение сторон.
- После успешного повтора настройка разрешения переключается на «Авто», чтобы интерфейс не показывал значение, которое фактически не использовалось.
- Это устраняет ошибку Seedream 4.5 при широких форматах вроде `16:9`, когда фиксированное разрешение оказывается ниже фактического минимума модели.

## v1.2.0-beta.6 - 2026-09-11

- В сворачиваемом разделе «Генерация изображений» добавлена кнопка «Параметры изображения».
- Для моделей OpenRouter Umnik читает допустимые `aspect_ratio` и `resolution` из `/images/models` и показывает только поддерживаемые моделью варианты.
- Соотношение сторон и разрешение передаются в Image API отдельными параметрами, поэтому, например, `16:9` теперь задаётся не только текстом промпта.
- Параметры запоминаются отдельно для каждой модели и подключения; режим «Авто» ничего лишнего в API не отправляет.
- В плашке «Генерация изображения» перед отправкой видны текущие параметры, например `Seedream 4.5 · 16:9 · 2K`.
- Для произвольных OpenAI-совместимых подключений параметры остаются в режиме «Авто», пока сервер не предоставляет единый совместимый способ сообщить поддерживаемые размеры.

## v1.2.0-beta.5 - 2026-09-11

- Убрано лишнее всплывающее уведомление при переключении быстрой модели: выбранная модель и так сразу видна в заголовке чата.
- Остальные уведомления подняты над полем ввода и получили более спокойный тёмно-серый фон, чтобы не перекрывать набор текста и не выбиваться из тёмной темы.

## v1.2.0-beta.4 - 2026-09-11

- В поле ввода добавлен микрофон для голосовых сообщений. Он активен только у моделей OpenRouter, которые в метаданных заявляют поддержку аудиовхода.
- Голос записывается локально в WAV PCM 16-bit mono 16 kHz и отправляется модели напрямую как аудио без предварительного распознавания в текст.
- Во время записи показываются пульсирующий индикатор, таймер и кнопка отмены; кнопка отправки завершает запись и сразу отправляет голосовое сообщение.
- Повторное нажатие на микрофон завершает запись и оставляет WAV вложением, чтобы при желании добавить текст перед отправкой.
- На моделях без поддержки аудио микрофон остаётся видимым, но неактивным. Максимальная длительность одной записи — 10 минут.

## v1.2.0-beta.3 - 2026-09-11

- Модель генерации изображений теперь можно выбирать из любого включённого подключения, а не только из OpenRouter.
- Для OpenAI-совместимых подключений Umnik использует стандартный `/images/generations`; список моделей берётся из `/models`, поэтому пользователь сам выбирает подходящую image-модель.
- Изображения-референсы пока оставлены только для OpenRouter, потому что формат image edit у совместимых API не унифицирован.
- Исправлен звук готового ответа: основной и пользовательский сигнал теперь используют медиаканал устройства вместо канала уведомлений.
- В настройках звука добавлена кнопка «Проверить звук».

## v1.2.0-beta.2 - 2026-09-11

- Генерация изображений больше не переключает весь чат в отдельный режим: «+ → Создать» подготавливает один изолированный запрос в текущем диалоге.
- Над полем ввода появляется подсказка «Генерация изображения» с выбранной моделью; после отправки Umnik автоматически возвращается к обычному текстовому вводу.
- Запрос к модели изображений не получает историю чата, навыки, мастер-промпты, постоянные файлы и другие текстовые контексты — только текущий промпт и явно приложенные изображения-референсы.
- Выбор модели генерации изображений вынесен в отдельный сворачиваемый раздел настроек.
- Верхний селектор модели всегда остаётся селектором текстовой модели.

## v1.1.1 - 2026-09-11

- Дополнительные OpenAI-совместимые профили теперь намеренно работают в безопасном текстовом режиме: Umnik не включает фото, reasoning, tools или другие возможности, пока для них не реализован совместимый формат конкретного провайдера.
- OpenRouter по-прежнему использует полный набор возможностей и автоматические метаданные моделей.

## v1.1.0 - 2026-09-11

- В настройках появились профили подключения: встроенный OpenRouter и дополнительные OpenAI-совместимые API.
- Для OpenRouter теперь можно изменить базовый адрес API; все существующие возможности OpenRouter, включая метаданные моделей, reasoning, web search и генерацию изображений, сохранены.
- Дополнительные профили загружают модели через `/models` и работают с текстовым `/chat/completions`; неподтверждённые возможности намеренно не включаются автоматически.
- API-ключ каждого профиля хранится отдельно и шифруется через Android Keystore.

## v1.0.0 - 2026-09-11

- Первая стабильная версия Umnik 1.0.0.
- Действие «Ветка в новом чате» под ответом модели теперь отображается компактным нейтральным значком без длинной подписи и акцентного цвета.
- Сохранена возможность создавать независимую ветку диалога от любого ответа модели.

## v0.7.9 - 2026-09-11

- Ответы модели теперь отображаются прямо на фоне чата без отдельной карточки.
- Сообщения пользователя получили более лёгкое, едва заметное выделение.
- Под ответами модели добавлена кнопка «Ветка в новом чате»: она создаёт независимую копию диалога до выбранного ответа и позволяет продолжить разговор отдельно.

## v0.7.8 - 2026-09-11

- Логотип и вопрос «Чем могу помочь?» на пустом экране уменьшены и сделаны менее акцентными.
- Пустое состояние теперь центрируется одновременно по ширине и по высоте свободной области чата.
- Значок нового чата заменён на понятную иконку сообщения с плюсом.

## v0.7.7 - 2026-09-11

- Главное окно пустого чата стало чище: карточка «Готов к работе» заменена на центральный экран приветствия с логотипом Umnik и текстом «Чем могу помочь?».
- Кнопка нового чата в верхней панели получила отдельный контурный значок вместо обычного плюса.
- Добавлен новый монохромный логотип Umnik в виде модульной буквы U, который не зависит от выбранной цветовой схемы.
- Иконка приложения обновлена под новый логотип.

## v0.7.0 - 2026-09-09

### Changed

- Введена постоянная release-подпись приложения для публичных GitHub Releases.
- Публичная сборка теперь использует отдельный release keystore вместо временной debug-подписи.

- Для релизного APK публикуется SHA-256 checksum.
- Репозиторий подготовлен к нормальным обновлениям приложения поверх установленной версии, начиная с этой ветки подписи.

### Important

- v0.7.0 является базовой версией новой постоянной подписи.
- Старые preview-сборки v0.6.x были подписаны тестовым ключом. Android может потребовать удалить установленную v0.6.x перед установкой v0.7.0.
- После установки v0.7.0 следующие релизы, подписанные тем же ключом, должны обновляться поверх неё без переустановки.
