- Удалены NVIDIA и произвольные OpenAI-compatible подключения, реестр провайдеров и связанные настройки. Единственное подключение — OpenRouter с официальным API endpoint.
- Полностью удалена старая архитектура проектных этапов и старый чат-оркестратор. Проект теперь только кабинет, а инструкции, навыки, файлы, память и база знаний принадлежат конкретным агентам.

- Исправлен FileProvider для импорта навыков.
- Файлы проверяются по фактически записанному размеру после копирования; частично записанные файлы удаляются при ошибке. Для прямых вложений одного запроса введён общий лимит 50 МБ с ограниченным чтением.
- Копирование файлов, импорт навыков и сохранение сгенерированных файлов перенесены с главного UI-потока на Dispatchers.IO.
- Навыки получили лимиты на отдельный файл, дерево и суммарный текст, передаваемый модели; повреждённые индексы защищены от молчаливой перезаписи.
- Recovery OpenRouter больше не сохраняет полный payload запроса: на диске остаются только технические идентификаторы, необходимые для безопасной read-only проверки уже созданной генерации.

- Локальная release-сборка без постоянного ключа теперь остаётся неподписанной и не может незаметно использовать debug-сертификат.
- README, Privacy, памятка и архитектурная документация приведены к Android-only/OpenRouter-only модели.
- Интерфейс чата упрощён: слева сверху круглая кнопка боковой панели, справа — круглая кнопка меню, а название чата остаётся по центру и не является кнопкой. Баланс, выбор модели и очистка перенесены в компактное меню.
- В меню чата добавлен поиск по переписке со счётчиком совпадений, переходом к предыдущему/следующему результату и подсветкой найденных сообщений.
- Общие настройки, боковая панель, проектные и агентные экраны приведены к единой визуальной системе Material 3: общие радиусы, поверхности, отступы, заголовки и кнопки навигации.

## v1.10.7 - 2026-09-14

## v0.7.0 - 2026-09-09

### Changed

- Введена постоянная release-подпись приложения для публичных GitHub Releases.
- Публичная сборка теперь использует отдельный release keystore вместо временной debug-подписи.

- Для релизного APK публикуется SHA-256 checksum.
- Репозиторий подготовлен к нормальным обновлениям приложения поверх установленной версии, начиная с этой ветки подписи.

- v0.7.0 является базовой версией новой постоянной подписи.
- Старые preview-сборки v0.6.x были подписаны тестовым ключом. Android может потребовать удалить установленную v0.6.x перед установкой v0.7.0.
- После установки v0.7.0 следующие релизы, подписанные тем же ключом, должны обновляться поверх неё без переустановки.
