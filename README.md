# Umnik

**Umnik** — Android-клиент для OpenRouter: мультимодальный чат, проекты, навыки, файлы и разные ИИ-модели в одном рабочем контексте.

## Зачем Umnik

Главная идея Umnik — не привязывать рабочую задачу к одной модели. В одном чате можно менять модели без потери истории, подключать файлы и использовать дополнительные возможности OpenRouter только тогда, когда они нужны.

Например, одну модель можно использовать для разбора материала, другую — для продолжения работы, третью — для проверки результата. Проекты добавляют общие инструкции, файлы, навыки и последовательные этапы работы.

## Возможности

- OpenRouter `chat/completions` и единый каталог моделей;
- быстрые текстовые модели с переключением прямо в чате;
- Vision: фотографии и изображения для совместимых моделей;
- генерация изображений;
- web search и reasoning с отдельными переключателями в меню `+`;
- OpenRouter Speech / Transcription: озвучивание и распознавание речи;
- отдельная временная **OR-озвучка ответа** без сохранения MP3 в чат: звук запускается автоматически после подготовки и останавливается повторным нажатием;
- обычная локальная Android Text-to-Speech озвучка;
- Batch с отдельными задачами, отдельными текстовыми файлами для каждой задачи и очисткой истории;
- фоновые Video-задачи с возвратом результата в исходный чат;
- Shell для вычислений и работы с временными файлами;
- Embeddings, RAG и Rerank для поиска по своим текстовым материалам;
- проекты с мастер-инструкцией, файлами, навыками и универсальными **этапами работы**;
- этапы проекта выполняются строго по порядку, следующий этап получает результаты предыдущих;
- локальные навыки из текстовых файлов и `SKILL.md`;
- постоянные файлы проекта и файлы конкретного чата;
- компактное локальное хранилище созданных файлов;
- Markdown в ответах модели;
- ветвление разговора от выбранного ответа;
- избранные чаты, переименование и действия через `⋮` / долгий тап;
- встроенная **Памятка Umnik** для новичка, открывающаяся локально без расхода API;
- расширенная диагностика и экспорт логов без API-ключей и текста личных сообщений;
- Material 3 / Material You и пользовательский Accent Color.

Поддержка изображений, reasoning, аудио, видео, tools и других возможностей зависит от конкретной модели и endpoint OpenRouter.

## Проекты и этапы работы

Проект объединяет связанные чаты, общие файлы, навыки и мастер-инструкцию.

В проект можно добавить произвольные **этапы работы**. Они не привязаны к написанию статей: это универсальная последовательность для любой задачи. Каждый этап выполняется отдельным запросом, строго сверху вниз. При необходимости для этапов можно использовать разные модели.

Пример общей схемы:

1. изучить входные материалы;
2. выполнить первый тип обработки;
3. использовать результат предыдущего этапа для следующего действия;
4. проверить итог по отдельной инструкции.

## Batch

Batch предназначен для **независимых** задач, которые не должны передавать результат друг другу.

В интерфейсе каждая задача имеет собственное поле и собственные текстовые вложения. Никакие ручные разделители вводить не нужно. Для последовательной цепочки зависимых шагов используйте **этапы проекта**, а не Batch.

## Файлы

В Umnik есть три основных уровня файлового контекста:

- **Файлы проекта** — постоянные и доступны чатам этого проекта.
- **Файлы чата** — текстовые документы и PDF остаются доступны следующим запросам в том же диалоге.
- **Разовые вложения** — например, фото, аудио и видео для конкретного сообщения.

Обычный длинный ответ модели не превращается автоматически в скачиваемый файл. Файл создаётся, когда пользователь явно просит его получить либо это прямо требуется инструкцией, проектом или навыком.

## Скачать

**[Последний опубликованный стабильный релиз Umnik](https://github.com/Ayuemin/Umnik/releases/latest)**

В Assets официального релиза публикуются:

- `Umnik-vX.Y.Z.apk` — установочный APK;
- `Umnik-vX.Y.Z.apk.sha256` — SHA-256 APK;
- `Umnik-signing-certificate-sha256.txt` — отпечаток постоянного release-сертификата.

Требования:

- Android 8.0+;
- API-ключ OpenRouter;
- доступ к сети.

После установки откройте **Настройки → OpenRouter**, сохраните API-ключ и проверьте подключение. Затем откройте **Настройки → Модели → Каталог и модели OpenRouter** и назначьте нужные модели.

### Постоянная подпись

Начиная с v0.7.0 официальные GitHub Releases подписываются постоянным release-ключом Umnik. Подпись APK проверяется автоматически в GitHub Actions.

SHA-256 сертификата постоянной подписи:

`bc0c8bfe9031c29fc3148fdc52c1cb84d897682b83af73e37f3af670f047d79e`

## Приватность

Umnik не содержит встроенного API-ключа и не отправляет ваш ключ автору приложения. Ключ OpenRouter хранится локально в приватном хранилище приложения и шифруется через Android Keystore.

При запросе модели текст и выбранные вложения отправляются в OpenRouter и далее могут обрабатываться выбранным провайдером модели. Подробности: [PRIVACY.md](PRIVACY.md).

Диагностический журнал не должен содержать API-ключи и текст личных сообщений. Он фиксирует технические события, сетевые этапы, выбранные режимы, возврат результатов и ошибки.

## Сборка

Стек:

- Kotlin;
- Jetpack Compose;
- Material 3;
- OkHttp;
- Gson;
- Android minSdk 26, targetSdk 36.

Для локальной debug-сборки нужен JDK 17, Android SDK и Gradle 8.13:

```bash
gradle :app:assembleDebug
```

Локальный `assembleRelease` без release-ключа не является официальной публичной сборкой. Официальные APK собираются GitHub Actions с постоянным ключом проекта.

## Релизы

Обычные push в `main` запускают CI, но не публикуют новый APK автоматически.

Официальный релиз должен использовать тег `vX.Y.Z`, совпадающий с `versionName`, после чего workflow **Android Release** выполняет тесты, собирает подписанный APK, проверяет сертификат и публикует GitHub Release.

История пользовательских изменений находится в [CHANGELOG.md](CHANGELOG.md).
