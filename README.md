# Умник

Android-клиент для работы с моделями через OpenRouter.

Первая версия проекта закладывает:
- чат с моделями OpenRouter;
- локальные навыки в формате Markdown/Text;
- прикрепление файлов;
- сохранение созданных моделью файлов;
- безопасное хранение API-ключа;
- озвучивание ответов через системный Android Text-to-Speech;
- автоматическую сборку APK в GitHub Actions.

> Проект находится в активной разработке.
