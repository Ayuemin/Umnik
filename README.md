# Umnik

**Umnik** — Android-клиент для OpenRouter: мультимодальный чат, проекты, навыки, файлы и быстрая смена моделей без потери контекста.

[![Android CI](https://github.com/Ayuemin/Umnik/actions/workflows/android-ci.yml/badge.svg)](https://github.com/Ayuemin/Umnik/actions/workflows/android-ci.yml)
[![Latest release](https://img.shields.io/github/v/release/Ayuemin/Umnik?display_name=tag)](https://github.com/Ayuemin/Umnik/releases/latest)

> Проект создан Александром ([@Ayuemin](https://github.com/Ayuemin)) **в соавторстве с ChatGPT от OpenAI**. Александр определяет идею, требования, UX и тестирует приложение; ChatGPT участвует в проектировании, реализации, отладке и документации. Это описание совместной разработки и не означает, что OpenAI является владельцем, издателем или спонсором проекта.

A local-first Android client for OpenRouter with multimodal chat, projects, skills and per-chat model switching.

## Зачем Umnik

Главная идея — не привязывать рабочий диалог к одной модели. Один ИИ может разобрать материал, второй продолжить работу с тем же контекстом, третий — проверить результат. При этом файлы, настройки проекта и история остаются в одном чате.

Пример рабочего процесса:

1. прикрепить транскрипцию;
2. попросить одну модель разобрать материал;
3. мгновенно переключить модель внутри того же чата;
4. попросить другую модель написать статью на основе уже накопленного контекста;
5. при необходимости передать результат третьей модели для критики.

## Возможности

- OpenRouter `chat/completions` и выбор моделей;
- быстрая смена текстовой модели внутри текущего чата без потери текстовой истории;
- компактный главный экран с быстрым выбором модели, новым чатом и единым меню;
- панель действий по кнопке `+`: файл, камера, режим изображений, web search и reasoning;
- проекты с собственными инструкциями, ролью, навыками и постоянными файлами;
- временные файлы конкретного чата: текстовые документы и PDF автоматически остаются доступными следующим запросам в этом диалоге;
- мультимодальные вложения через одну кнопку: изображения, PDF, аудио, видео и текстовые файлы — если выбранная модель поддерживает соответствующий тип входа;
- быстрая камера для моделей с image input;
- ручные переключатели web search и reasoning;
- проверка возможностей выбранной модели до отправки несовместимого вложения;
- остановка активного запроса кнопкой Stop с мягкой пульсацией во время работы модели;
- локальные навыки из `SKILL.md`, отдельных файлов и папок;
- несколько локальных чатов и избранное;
- Android Text-to-Speech для ответов;
- создание текстовых файлов моделью через локальный tool `create_file`;
- локальное хранилище созданных файлов и очистка рабочих данных;
- короткий профиль пользователя с областью применения `выкл / только проекты / везде`;
- Material 3 / Material You.

Поддержка reasoning, изображений, аудио, видео, tools и других возможностей зависит от конкретной модели и её endpoint в OpenRouter.

После установки откройте **Настройки**, добавьте API-ключ, обновите список моделей и выберите основную модель.

### Постоянная подпись

**v0.7.0 — базовая версия постоянной release-подписи Umnik.** Публичный APK собирается в GitHub Actions с отдельным release keystore, после чего подпись автоматически проверяется через Android `apksigner`, а сертификат APK сверяется с сертификатом постоянного ключа проекта.

Сборки v0.6.x были подписаны временным тестовым ключом. Поэтому при переходе с v0.6.x на v0.7.0 Android может потребовать удалить старую установку. Начиная с v0.7.0 последующие официальные релизы, включая v0.7.1, подписаны тем же ключом и должны устанавливаться поверх приложения обычным обновлением.

SHA-256 сертификата постоянной подписи:

`bc0c8bfe9031c29fc3148fdc52c1cb84d897682b83af73e37f3af670f047d79e`

## Как устроены файлы

В Umnik есть три уровня файлового контекста.

**Файлы проекта** — постоянные и доступны всем чатам проекта.

**Файлы чата** — текстовые документы и PDF, добавленные через скрепку. Они автоматически копируются во внутреннее хранилище приложения и повторно передаются моделям в следующих запросах этого же чата. В другой чат они не переходят. При удалении или очистке чата удаляются и его временные файлы.

**Разовые вложения** — изображения, аудио и видео для конкретного сообщения. Они не превращаются в постоянный контекст автоматически.

## Навыки

Навык может быть отдельным текстовым файлом или папкой с `SKILL.md` и дополнительными материалами.

Umnik **не исполняет произвольные скрипты** из папок навыков. Разрешённые текстовые материалы добавляются в системный контекст модели. Это позволяет использовать привычную структуру навыков без автоматического запуска `.py`, `.js`, shell-скриптов и другого кода.

## Приватность

Umnik не содержит встроенного API-ключа и не отправляет его автору приложения. Ключ хранится локально в приватном хранилище приложения и шифруется ключом Android Keystore.

При обращении к модели текст и выбранные вложения отправляются в OpenRouter и далее могут обрабатываться выбранным провайдером модели. Подробности: [PRIVACY.md](PRIVACY.md).

## Сборка

Стек:

- Kotlin;
- Jetpack Compose;
- Material 3;
- OkHttp;
- Gson;
- Android minSdk 26, targetSdk 36.

Для локальной сборки нужен JDK 17, Android SDK и Gradle 8.13.

```bash
gradle :app:assembleDebug
```

Локальный `assembleRelease` без release-ключа использует debug signing только для разработки. Публичные GitHub Releases собираются с постоянным ключом проекта.

## Релизы

Обычные push в `main` только проходят CI и **не создают новый GitHub Release**.

Публичный релиз создаётся из тега `vX.Y.Z`, который обязан совпадать с `versionName` приложения. Workflow восстанавливает release keystore из GitHub Secrets, собирает APK, проверяет его подпись и соответствие сертификату проекта, создаёт SHA-256 checksum и формирует release notes из `CHANGELOG.md`.

Инструкция для сопровождающего: [docs/RELEASING.md](docs/RELEASING.md).
