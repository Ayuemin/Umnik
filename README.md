## Что это

Umnik работает с моделями OpenRouter прямо с Android-устройства. Приложение не предоставляет собственную подписку на нейросети: для работы нужен личный API-ключ OpenRouter, а запросы оплачиваются по тарифам выбранных моделей.

Основные части приложения:

- обычные чаты с файлами, изображениями, аудио, reasoning и веб-поиском там, где это поддерживает модель;
- проекты с несколькими отдельными чатами, общей инструкцией и общими материалами;
- навыки — локальные инструкции и текстовые материалы, которые можно подключать к работе;
- базы знаний для больших документов с локальным хранением индекса;
- Оркестратор проекта для передачи задач и результатов между его чатами.

Подробности по отдельным возможностям вынесены в папку [`docs`](docs/).

## Установка

1. Скачайте APK из [Releases](https://github.com/Ayuemin/Umnik/releases/latest).
2. Установите приложение на Android 8.0 или новее.
3. Откройте **Настройки → OpenRouter**.
4. Добавьте свой API-ключ и проверьте подключение.
5. Выберите модель и начните новый чат.

Официальные релизы подписываются постоянным ключом проекта. В Assets также публикуются SHA-256 APK и отпечаток сертификата подписи.

## Важное ограничение фоновой работы

Длительные запросы в прямом режиме наиболее надёжно выполнять, пока Umnik открыт и экран устройства активен.

Android и особенно отдельные прошивки производителей могут ограничить или остановить сетевую работу приложения после сворачивания или выключения экрана. Поэтому текущая стабильная версия **не гарантирует**, что длинный запрос завершится в фоне на каждом устройстве.

Это ограничение не скрывается и не считается решённым только наличием уведомления или WorkManager. Для следующих версий исследуются штатный Android-механизм User-Initiated Data Transfer (UIDT) и дополнительный режим с личным сервером.

## Данные и приватность

Чаты, проекты, навыки, настройки и локальные индексы баз знаний хранятся на устройстве.

API-ключ OpenRouter хранится локально с использованием Android Keystore. При выполнении запроса необходимые данные отправляются выбранному внешнему API. У Umnik нет собственного облачного аккаунта или сервера, через который обязательно проходит переписка.

## Сборка

Проект использует Kotlin, Jetpack Compose и Material 3. Минимальная версия Android — API 26.

CI собирает и тестирует приложение через GitHub Actions. Официальный APK создаётся отдельным release workflow и подписывается ключом проекта.
