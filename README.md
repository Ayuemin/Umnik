# Умник

**Умник** — Android-клиент для работы с моделями через OpenRouter с локальными навыками и файлами.

## Что уже есть в v0.1.0

- чат через OpenRouter `chat/completions`;
- выбор ID модели и загрузка списка моделей;
- API-ключ хранится зашифрованно через Android Keystore;
- прикрепление файлов через системный Android file picker;
- изображения отправляются как multimodal `image_url`, PDF/бинарные файлы — как `file`, текстовые файлы добавляются в контекст;
- импорт одного файла навыка (`.md`, `.txt`, `.json`, `.yaml`, `.yml`);
- импорт целой папки навыка, включая `SKILL.md` и дополнительные текстовые материалы;
- одновременное подключение нескольких навыков;
- tool calling через OpenRouter;
- локальный инструмент `create_file`: модель может создать файл, после чего пользователь сохраняет его через Android Storage Access Framework;
- озвучивание ответов модели через системный Android Text-to-Speech: кнопка `🔊 Озвучить` находится прямо в карточке ответа, повторное нажатие останавливает чтение;
- история чата сохраняется локально.

## Как навыки работают

Умник не пытается исполнять произвольные скрипты из папки навыка. Текстовые материалы выбранных навыков подмешиваются в системную инструкцию модели. Это делает формат совместимым с привычным `SKILL.md`, не открывая приложению опасное автоматическое выполнение кода.

Модель также получает разрешённые приложением инструменты. В v0.1.0 доступен `create_file`. Архитектуру можно расширять новыми локальными инструментами.

## Озвучивание

Для чтения ответов используется установленный в Android TTS-движок. Дополнительный платный API для озвучивания не нужен. Длинные ответы автоматически делятся на части, а Markdown, ссылки и большие блоки кода упрощаются перед чтением, чтобы речь звучала естественнее.

Наличие русского голоса и возможность работы полностью офлайн зависят от установленного на устройстве TTS-движка и загруженных голосовых данных.

## Сборка

Проект использует Kotlin, Jetpack Compose и Material 3.

```bash
gradle :app:assembleRelease
```

GitHub Actions собирает установочный APK и прикладывает его к GitHub Release `v0.1.0`.

> Первая тестовая версия подписывается debug-ключом сборочной среды. Перед публичным распространением и регулярными обновлениями приложение нужно перевести на постоянный release keystore.

## OpenRouter

После установки откройте **Настройки**, вставьте свой API-ключ OpenRouter и выберите модель. Ключ не включён в APK и не хранится в репозитории.

## Ограничения первой версии

- лимит вложения в интерфейсе: 25 МБ на один файл;
- большие папки навыков ограничены текстовыми материалами суммарно примерно до 4 МБ;
- поддержка tool calling зависит от выбранной модели OpenRouter;
- `create_file` создаёт текстовые файлы. Бинарные генераторы можно добавить отдельными инструментами в следующих версиях.
