# Umnik 1.5.2: universal project instruction priority

This correction removes task-specific behavior introduced in 1.5.1.

- The app no longer detects a ban on long dashes or rewrites model output based on that rule.
- No article-writing, plagiarism, punctuation, names, examples, or other domain-specific rules are embedded in the priority mechanism.
- The only retained behavior is a generic instruction hierarchy for projects.
- The model is explicitly told not to invent requirements that are absent from the user's project master instruction.

Version: 1.5.2 / versionCode 56.
