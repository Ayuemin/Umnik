### Главное

- Текущая архитектура переименована и приведена к единой терминологии: **Команды**, **Специалисты** и **Оркестратор** вместо прежних пользовательских «проектов» и «агентов», с миграцией старых локальных данных.
- Добавлен **Local Browser** для реальной работы с публичными веб-страницами: чтение, переходы, прокрутка, ввод, скачивание файлов и передача результата в чат и Local Shell.
- Добавлен новый **Local Shell** с локальной рабочей областью, файлами, Python, архивами, экспортом результата и безопасными Git-операциями через JGit.
- Git в Local Shell защищён от ручной подмены `.git`; добавлены проверки псевдорепозиториев, защита Python-записей, anti-loop/circuit-breaker, sticky-success, checkpoint состояния и сетевые watchdog'и.
- Улучшена работа с историческими вложениями, долгими инструментальными задачами и возвратом файлов между Browser, Shell и чатом.
- Панель **«Об ответе»** и диагностический журнал получили более подробные сведения о контексте, токенах, стоимости и ходе выполнения инструментов.
- База знаний продолжает использовать локальный индекс и OpenRouter Embeddings, поддерживает самостоятельный `knowledge_search` совместимых моделей и изоляцию между чатами и специалистами.
- Обновлены README и документация проекта под фактическое состояние Umnik 1.20.

### Совместимость

- Android 8.0+ (API 26+).
- В этой версии встроенный Python Local Shell собирается для 64-битных ABI: `arm64-v8a` и `x86_64`.
- GitHub APK подписан постоянным ключом Umnik и устанавливается как обновление предыдущих официальных GitHub-сборок.
