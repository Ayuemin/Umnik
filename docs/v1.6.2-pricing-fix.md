# Umnik 1.6.2 — корректная цена OpenRouter Hub

Исправление основано на реальном тестировании image-моделей OpenRouter.

- Нулевые `prompt`/`completion` больше не означают бесплатную генерацию изображения.
- Для image-моделей учитываются `image_output` и `image_token` из каталога OpenRouter.
- Фильтр «Бесплатно» проверяет стоимость выбранной модальности и не показывает платные image-модели без `:free`.
- Для изображений денежные пороги отображаются как ориентировочная стоимость 1K-выхода; точная стоимость конкретного запроса по-прежнему определяется OpenRouter и зависит от модели, разрешения, качества и провайдера.
- При ценовом фильтре список сортируется от более дешёвых моделей к дорогим.
- У карточки модели снова есть контекстное меню с выбором назначения, быстрыми моделями и копированием ID.
