# Umnik v1.5.0 navigation update

- Left drawer (~72% width) opens from header button or left-to-right swipe.
- Projects appear first, chat history below in one vertically scrollable list.
- Chats and projects can be pinned.
- Search is available at the top of the drawer.
- New chat and Menu actions moved to the drawer bottom.
- Main chat header now keeps only drawer, balance and quick model controls.
- Project chat rows include delete with confirmation.
